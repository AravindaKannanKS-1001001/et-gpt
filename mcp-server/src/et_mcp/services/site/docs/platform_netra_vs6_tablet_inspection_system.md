# Netra VS6 Tablet Inspection System

## Platform Overview

Netra VS6 is an automated tablet inspection system designed for pharmaceutical manufacturing environments.

The system uses six industrial vision cameras to perform high-speed, 360-degree inspection of tablets. It is designed to detect manufacturing defects, automate quality inspection, maintain inspection records, and support regulatory compliance.

The source material states that Netra VS6 is compliant with FDA 21 CFR Part 11 requirements.

## System Architecture

### Six-Camera Vision System

Netra VS6 uses:

- 6 industrial vision cameras

The cameras collectively inspect the entire tablet surface and generate a composite 360-degree view.

### Inspection Resolution

The source material states that the system inspects every 100 microns of each tablet.

### Image Processing

Inspection data is processed using a high-speed computing system that analyzes image data captured by the cameras.

## Rejection System

### Rejection Mechanism

Rejected products are removed using:

- Pneumatic rejection ports
- Compressed air

### Rejected Product Handling

Rejected products:

1. Leave the inspection line through rejection ports.
2. Travel through collection chutes.
3. Are deposited into a collection bin.
