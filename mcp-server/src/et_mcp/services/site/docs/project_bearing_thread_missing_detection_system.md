# Bearing Thread Missing Detection System

## Project Overview

The Bearing Thread Missing Detection System is a vision-based inspection solution developed for automotive components.

The system is designed to detect thread-related defects in bearings while also verifying the presence, absence, and orientation of the component.

The solution uses advanced image processing techniques and automated machine vision to improve inspection reliability and reduce dependence on manual visual inspection.

---

## Inspection Objectives

The system performs the following inspections:

### Thread Defect Detection

- Detection of missing threads in bearings

### Presence and Absence Verification

- Verification of bearing presence
- Detection of missing components

### Orientation Verification

- Verification of bearing orientation

---

## Inspection Challenges

Bearings are circular components whose orientation can vary continuously.

Key challenge:

- Bearing orientation may vary from 0° to 360°

The developed inspection system is designed to detect and verify products despite significant angular variation.

---

## Vision System Design

### Imaging Hardware

The system uses:

- High-speed cameras
- High-accuracy cameras
- High-resolution lenses
- Low-distortion lenses

These components are used to capture clear and detailed images of bearings for inspection.

### Illumination System

Bearings can produce reflections that affect image quality.

To address this challenge, the system uses:

- Special-purpose illumination units

The illumination system helps reduce reflection effects during image acquisition.

---

## Image Processing Capabilities

The inspection solution applies image processing techniques for:

- Thread inspection
- Presence verification
- Absence detection
- Orientation verification
- Bearing analysis under varying rotational positions

The system is capable of inspecting bearings across a full angular range from 0° to 360°.
