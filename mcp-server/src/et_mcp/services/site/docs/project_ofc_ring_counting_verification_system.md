# Ring Counting and Verification System for Optical Fiber Cables (OFC)

## Project Overview

The Ring Counting and Verification System is a high-speed machine vision solution designed for optical fiber cable manufacturing.

The system performs automated ring counting and ring verification on optical fiber cables during production. It is designed to inspect cables at manufacturing speeds while providing real-time defect detection, alarm generation, and inspection data logging.

The solution supports quality control, traceability, and compliance with manufacturing specifications.
