# Sealing Inspection Using Thermal Cameras

## Project Overview

The Sealing Inspection System is a thermal imaging solution designed for inspection of sealed sachets and pouches in packaging environments.

The system uses thermal cameras positioned immediately after the sealing station to inspect seal quality and identify sealing defects during production.

Inspection is performed on both horizontal and vertical seals to verify seal integrity and support product quality, safety, and regulatory compliance.
