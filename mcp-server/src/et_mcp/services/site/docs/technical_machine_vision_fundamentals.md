# Machine Vision Fundamentals

## Technical Overview

Machine vision is used in manufacturing industries to maintain and improve product quality without intervening with the manufacturing process.

A typical machine vision system comprises:

- Controller
    
- Camera
    
- Lens
    
- Illumination Unit
    
- Image Processing Software
    

---

# Image Processing

## Definition

Image processing involves converting a captured image into electrical signals using a CMOS image sensor.

The CMOS sensor converts light signals (photons) into electrical signals for digital processing.

After image acquisition, image processing operations can be performed to:

- Extract areas of interest
    
- Analyze shape
    
- Analyze size
    
- Analyze colour
    
- Evaluate inspection criteria
    

The processed image is used to determine whether the area of interest aligns with predefined specifications and allowable deviations.

---

# CMOS Image Sensor

## Definition

The Complementary Metal-Oxide-Semiconductor (CMOS) image sensor consists of:

- A photodiode for each pixel
    
- A transistor switch for each pixel
    

## Operation

The sensor converts incoming light into electrical signals for digital image processing.

Because each pixel can be amplified individually:

- Pixel signals can be amplified at the pixel level
    
- Signals can be retrieved directly and sequentially
    
- Higher operating speeds are possible compared to conventional CCD sensors

# ET XPro

## Overview

ET XPro is a programmable image processing software developed to simplify machine vision system programming.

The software is intended to allow users to configure and use machine vision applications without requiring specialist expertise.

---

## Available Tools

ET XPro includes the following tools:

- Find Shape
    
- Pixel Count
    
- OCR
    
- Blob
    
- 1D Code
    
- 2D Code
    
- Measure Position
    
- Width Measurement
    
- Fuzzy Measurement
    
- Fuzzy Position
    
- Diameter
    
- Colour Tool
    

---

## Primary Applications

ET XPro is mainly employed for:

### Verification

Checking whether required conditions or features are present.

### Recognition

Identifying patterns, characters, shapes, or codes.

### Inspection

Determining whether products conform to inspection requirements.

### Measurement

Performing dimensional or positional measurements.

---

## Additional Applications

ET XPro can also be used for:

- Guided robots
    
- Online inspection
    
- Multi-location product inspection
    

The software supports customized inspection workflows to accommodate inspection requirements at different product locations.

# Key Concepts

## Area of Interest (AOI)

The area of interest is the specific region within an image selected for inspection or analysis.

Image processing tools operate on this selected region to perform measurements, inspections, or recognition tasks.

---

## Inspection Judgment

Inspection results are compared against predefined specifications and allowable deviations.

The outcome is used to determine whether the inspected item satisfies the required criteria.
