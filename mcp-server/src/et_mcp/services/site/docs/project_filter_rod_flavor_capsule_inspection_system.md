# Filter Rod Flavor Capsule Inspection System

## Project Overview

The Filter Rod Flavor Capsule Inspection System is a machine vision solution designed for inspection of flavor capsules in cigarette filter rods.

The system verifies capsule presence and capsule position before the filter rod proceeds to subsequent manufacturing stages.

The solution performs automated inspection and provides real-time non-conformity reporting.

---

## Application Domain

### Industry

Tobacco Manufacturing

### Product Type

Cigarette Filter Rods

### Inspection Target

Flavor Capsules Embedded in Filter Rods

---

## Inspection Objectives

The system is designed to:

- Detect the presence of flavor capsules in filter rods
- Detect missing capsules
- Identify capsule position
- Prevent non-conforming filter rods from proceeding further in production
- Provide real-time inspection feedback

---

## Inspection Workflow

### Step 1: Filter Rod Inspection

Filter rods containing two capsules pass through a high-frequency switching light source.

### Step 2: Image Acquisition

A camera mounted parallel to the light source captures inspection data from the filter rods.

### Step 3: Data Processing

The Control Unit processes the captured inspection data.

### Step 4: Non-Conformity Detection

The system evaluates the filter rod and identifies non-conforming products.

### Step 5: Reporting

The Control Unit provides real-time reporting of inspection results and detected non-conformities.

### Step 6: Product Rejection

Filter rods without capsules are rejected at the tipping paper wrapping rejection station.

## Inspection Capabilities

### Capsule Presence Detection

The system verifies whether flavor capsules are present within the filter rod.

### Missing Capsule Detection

Filter rods with missing capsules can be identified and rejected.

### Capsule Position Identification

The system identifies the position of capsules within the filter rod.

### Multi-Color Capsule Detection

Capsules of any color can be detected.

---

## Automated Rejection

### Rejection Criteria

Products are rejected when:

- Flavor capsules are absent from the filter rod

### Rejection Location

- Tipping paper wrapping rejection station
