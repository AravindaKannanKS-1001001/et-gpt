# Tipping Paper Inspection System (TPI Inspection System)

## Project Overview

The Tipping Paper Inspection (TPI) System is a vision-based inspection and rejection system designed for cigarette manufacturing applications.

The system captures images of cigarettes during production, performs real-time image processing, identifies defects in the binding zone, and rejects non-conforming products automatically.

According to the source material, the system is designed to identify defects such as filter flagging, wandering, filter misalignment, and double batch conditions.

## System Operation

### Trigger-Based Inspection

The inspection process begins when a trigger signal is received from an external device.

Possible trigger sources include:

- Fiber sensors
    
- PLC systems
    
- Other external automation devices
    

### Image Capture

When the target reaches the inspection position, the trigger signal activates image acquisition.

The camera captures a still image of the target according to the configured shutter speed.

### Image Processing

The captured image is processed by the vision system.

The system evaluates the image and determines whether the product meets predefined inspection criteria.

### Result Generation

After inspection, the system generates an inspection result.

Possible outcomes include:

- OK
    
- NG (Not Good)
    

### Output Communication

Inspection results can be transmitted to external devices for process control and product handling.

---

## Inspection Capabilities

### Filter Flagging Detection

The system is designed to identify filter flagging defects within the binding zone.

### Wandering Detection

The system can detect wandering-related defects.

### Filter Misalignment Detection

The source material states that the system identifies misalignment between the filter base and the top zone of the cigarette.

### Double Batch Detection

The system can detect double batch conditions.

### Non-Conforming Product Detection

Products containing identified defects are classified as non-conforming.

---

## Automated Rejection System

### Purpose

The rejection system removes defective cigarettes from production.

### Operation

Inspection results generated by the vision system are transmitted to the rejection mechanism.

Products classified as NG are rejected automatically.

### Benefits

- Reduction of defective products
    
- Improved product quality
    
- Automated quality control
